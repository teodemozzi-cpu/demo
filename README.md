# SAXUM

Sito web del progetto SAXUM in HTML/CSS/JavaScript.

## Struttura
- `saxum26.html` : pagina principale del progetto
- `assets/images/` : immagini dei prodotti
- `scheda_altera.html`, `scheda_vertis.html`, `scheda_rocca.html` : schede prodotto
- `carrello.html` : pagina del carrello

## Pubblicazione su GitHub Pages
1. Crea un nuovo repository su GitHub.
2. Carica tutti i file del progetto.
3. Vai su `Settings > Pages`.
4. Seleziona la branch principale (`main`) e la cartella root.
5. Salva e attendi la pubblicazione.

Il sito sarà disponibile come pagina web pubblica da GitHub Pages.
